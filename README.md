# 新能源维修授权履历

记录新能源车型配置、维修授权、部件序列、技术公告、机构与技师资质、诊断证据、拆装事实、替换件来源、软件版本、质保承诺与保险案件，为跨机构维修履历提供一致契约。

## 目录

- `contracts/domain.schema.json`：事件信封、聚合类型、事件目录、各事件必填载荷、载荷枚举与时间字段约定。
- `data/sample.json`：可直接校验的中文联调样例（危险步骤双人签认）。
- `src/`：契约校验与命令行入口。
- `tests/`：基础字段、时间版本、事件载荷、载荷枚举与时间字段边界测试。
- `docs/domain.md`：聚合有效期、事件语义与业务规则（冻结工艺、双人签认、暂停重估、公告义务、幂等争议、替换件预留、脱敏证明、审计链、重启恢复）。

## 测试

```bash
npm test
```

## 编译检查

```bash
npm run build
```

## 样例校验

```bash
npm run check:sample
```

命令成功时输出 `valid`；校验失败时逐行输出字段、代码和中文说明，并以非零状态结束。
